## Interaction Design Decisions

### Form Sections (Tabs)
1. **Informações Gerais**: Course code, name, semester.
2. **Pedagogia**: Objectives and methodology.
3. **Cronograma**: Week-by-week schedule (Rich Text).
4. **Avaliação**: Evaluation methods and dates.
5. **Bibliografia**: Structured dynamic list of references.

### CSV Mapping UX
- **Step 1**: File upload (Drag & Drop).
- **Step 2**: Column selection (Map CSV headers to "Código" and "Nome").
- **Step 3**: Confirmation and bulk insert.
